# Representation Learning

A collection of projects exploring representation learning, dimensionality reduction, and machine learning.

## Projects

### 1. [PCA vs. NMF on MNIST](PCA-vs-NMF-MNIST)

A comparison of Principal Component Analysis (PCA) and Non-negative Matrix Factorization (NMF) for learning low-dimensional representations of handwritten digits.

The project examines classification performance, dimensionality reduction, and the interpretability of learned representations.
